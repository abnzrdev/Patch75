# Local transfer and future sync

Today, export a progress ZIP and send it through LocalSend, a USB cable, or
another transport you trust, then preview and import it on the other device.
The app never starts a server and never uploads automatically.

A future LAN sync can reuse the same validated archive and merge rules. It
should require explicit pairing, authentication, encryption, preview, and user
confirmation. No discovery or background network dependency is included now.
