# Run Code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Execute freeform Python from the editor and show stdout/errors in the
existing result console without changing Run Tests or Submit.

**Architecture:** Extend `JudgeRequest` with an explicit execution mode and
carry it through the existing desktop and Android transports. Branch inside
the already-sandboxed Python runners, then reuse `JudgeResult` and the current
workspace result panel.

**Tech Stack:** Flutter/Dart, Python, Android Chaquopy, Docker

## Global Constraints

- No interactive stdin in this version.
- Preserve existing Docker, Android service, payload, timeout, and output limits.
- Scratch runs must not mutate test history, solved progress, review telemetry,
  or submission state.
- Add no dependency or terminal emulator.
- Preserve unrelated generated plugin and diagnostic changes.
- Make one focused commit only after all tests and release builds pass.
