# Patch75 v1.0.0

This page documents the historical private `v1.0.0` build. It is not the
source or release candidate for the public edition and must not be republished.
This release includes the complete Linux x86_64 application bundle and an
installable Android APK.

## Highlights

- Historical 75-problem curriculum (content removed from the public edition)
- Python editor, per-problem drafts, notes, timer, and focus mode
- Run Code and structured Run Tests workflows
- Local hints, complexity checks, and learning materials
- FSRS review scheduling and portable progress archives
- No account, telemetry, analytics, advertising, or cloud sync

## Security

This note describes the historical v1.0.0 tag. The current branch disables
Linux structured Tests/Submit and is not source-equivalent to that release.
Linux scratch execution requires the local Docker judge bridge. Android executes
embedded Python in a separate, non-exported service process with a host timeout;
it is not a secure sandbox for hostile Python. User state remains local and is
preserved by the Linux uninstaller.
